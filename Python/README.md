# Python 历史版本存档

本目录收录了从 v1 到 v10 的所有 Python 实现。版本号跳跃是因为中间经历了多次内部重构，所有留存文件均按实际开发版本命名。

**⚠️ 重要提示**  
- 早期版本（v1~v4）存在 **压缩选项 bug**：若加密时未启用压缩，生成的密文无法解密。建议直接使用 v10 稳定版。
- v5、v6 为**图片隐写加载器**，它们依赖 v4 作为核心加密逻辑，并需要安装 `Pillow` 和 `requests` 库。
- 其余版本（v1~v4, v7~v10）**仅使用 Python 标准库**，无需额外安装。

## 📋 版本特性一览

| 文件 | 版本 | 主要特性 |
| :--- | :--- | :--- |
| `UC加密1.py` | v1 | 最简原型：zc 编码，无压缩，PBKDF2 迭代 10 万次 |
| `UC加密2.py` | v2 | 加入可选 zlib 压缩标志（但压缩开关有 bug） |
| `UC加密3.py` | v3 | 增加 Tkinter GUI 和命令行参数解析 |
| `UC加密4.py` | v4 | **流式分块处理**，支持超大文件，但仍保留可选压缩 |
| `UC加密5.py` | v5 | 从远程图片中隐写提取 v4 核心并执行（需网络） |
| `UC加密6.py` | v6 | 在 v5 基础上增加 URL 和图片内容的 SHA‑256 校验 |
| `UC加密7.py` | v7 | **强制启用压缩**，修复压缩 bug；PBKDF2 迭代提升至 60 万次 |
| `UC加密8.py` | v8 | 重构整体架构，统一流式编解码器，代码更清晰 |
| `UC加密9.py` | v9 | 引入 **zj 自解模式**（密码隐写在文件尾部） |
| `UC加密10.py` | v10 | **当前稳定版**：移除 zj，新增 **zh 汉字编码**（膨胀率更低） |
| `UC加密10特别版.py` | v10 分支 | 保留 zj 自解功能的特别版，与 v10 共享核心 |

**使用建议**：日常加密请使用 `UC加密10.py`，命令行或 GUI 均可。
